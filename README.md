# Ranking de Influenciadores

Painel web para acompanhar ranking mensal, clipes enviados, contas cadastradas, chave Pix e advertências.

## Estrutura atual

- Ranking mensal com premiação
- Detalhes dos clipes por participante
- Aba "Meus clipes"
- Aba "Minhas contas"
- Aba "Advertências"
- Modal "Enviar clipe"
- Layout responsivo inspirado na referência enviada

## Rodar localmente

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```
